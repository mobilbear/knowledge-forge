# Read a small pilot log

## Find the unit of observation

The [[10_sources/Thursday desk trial log#Trial setup|trial setup]] gives three one-hour shifts. Count hours before comparing the total with a longer or shorter trial.

## Work the example

Read the [[10_sources/Thursday desk trial log#Return tally|return tally]]. Add the completed returns (2 + 0 + 1), then divide by the three extra desk hours. The trial averaged **one completed return per extra desk hour**.

## Check what the tally can answer

A borrower stopped by to ask about a broken drill and carried it home. Would that visit appear in the tally?

**Answer** The log records completed returns. Count desk visits and completed returns separately if you want the next trial to measure both.
